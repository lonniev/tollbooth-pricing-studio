ENCRYPTION FUNCTIONALITY:

The application implements the following cryptographic algorithms for
the Nostr decentralized messaging protocol:

1. AES-256-CBC (NIP-04) — Encrypt/decrypt peer-to-peer direct messages
   using ECDH shared secret on secp256k1.

2. ChaCha20 + HMAC-SHA256 (NIP-44v2) — Encrypt/decrypt gift-wrapped
   private messages using HKDF-SHA256 key derivation and ECDH on
   secp256k1.

3. Schnorr Signatures (BIP-340) — Sign Nostr events for identity
   verification using secp256k1 elliptic curve with SHA-256 hashing.

4. ECDH Key Agreement — secp256k1 elliptic curve Diffie-Hellman for
   deriving shared encryption keys between Nostr identities.

5. HKDF-SHA256 (RFC 5869) — Key derivation for NIP-44v2 message
   encryption.

6. Standard HTTPS/TLS — All network communication uses TLS via Apple's
   URLSession framework.

The application does not implement any proprietary or novel
cryptographic algorithms. All encryption follows published open
standards (Nostr NIPs, BIP-340, RFC 5869).

The source code is publicly available at the URL listed above under
